## About

I build AI systems for production, with a focus on **agentic AI**: LLM agents that use tools, hand work to each other and pause for human approval before risky actions. My work covers ML pipelines on AWS and the Python backends that serve them. I care most about reliability, cost control, guardrails and observability.

|---|---|

| **Backend** | Python, FastAPI, Django, Flask, REST APIs |
| **Data** | PostgreSQL, Pandas, XGBoost |
